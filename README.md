# 大阪・タワーマンション宿泊事業シミュレーター for YI

大阪市内のタワーマンション一室を想定し、運営モデルと物件の確保方法による事業性・収支を比較するための試算ツールです。

[シミュレーターを開く](https://halmyzk.github.io/osaka-real-estate-investment-simulator-for-yi/)

事業設計、成立条件、収支分析、試算の前提と根拠を画面上で確認できます。入力内容に基づく数値は仮定による概算であり、収益の保証や、個別物件の営業可否・法令適合性を示すものではありません。実際の投資・契約・運営に際しては、物件条件、管理規約、法令、費用および市場データを別途確認してください。
