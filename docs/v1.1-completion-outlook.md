## 今回の達成点：国税庁給与源泉徴収月額表

- `src/nta-monthly-withholding.mjs` は国税庁の2026年・2027年の**個別行を限定的に**転記し、2026年甲欄0人は105,000円未満、2027年甲欄0人は111,000円未満で0円という年度差を独立照合。上限の端数（含む／含まない）、0人と1人、29.9万〜30.2万円の年差額も検算。
- 2026年公式資料：https://www.nta.go.jp/publication/pamph/gensen/zeigakuhyo2026/data/all.pdf （月額表の1〜2ページ）
- 2027年公式資料：https://www.nta.go.jp/publication/pamph/gensen/zeigakuhyo2027/data/01-07.pdf （月額表の1〜2ページ）
- `src/officer-payroll-withholding.mjs` に接続し、`lookupStatus=officialTableVerified` でも甲欄の**扶養控除等申告書提出と扶養人数のレビュー**を欠く場合はCF生成を保留。
- 対応外の給与額・賞与・乙欄・丙欄・扶養人数8人以上・未対応年度は、**税額0円と推定せず`incomplete`**。事前入力のシナリオ仮定による試算と、公式の該当行を照合済みの試算を区別する。
- `tests/nta-monthly-withholding.test.mjs` に公式数値・上下限・負のケースを記録。公式数値の全部分母へ展開したものではない。

## 作業方針

- GitHub `develop/v1.1-foundation` のみで開発し、`main`・公開 `index.html`・既存保存データは更新しない。
- 未確認の法令特例・控除・還付を、自動で課税額0／所得税還付に変換しない。
- 個別の`estimated`・`computed`・`incomplete`・`notApplicable`をUI実装後も保持する。
- 将来の税制改正やユーザーが選ぶ投資期間によって、標準モードの対応年度・詳細モードの非対応事象が発生するため、法定適格性のレビューが不可欠。
