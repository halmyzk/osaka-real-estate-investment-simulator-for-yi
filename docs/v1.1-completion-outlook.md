## 作業方針

- GitHub `develop/v1.1-foundation` のみで開発し、`main`・公開 `index.html`・既存保存データは更新しない。
- 未確認の法令特例・控除・還付を、自動で課税額0／所得税還付に変換しない。
- 個別の`estimated`・`computed`・`incomplete`・`notApplicable`をUI実装後も保持する。
- 将来の税制改正やユーザーが選ぶ投資期間によって、標準モードの対応年度・詳細モードの非対応事象が発生するため、法定適格性のレビューが不可欠。
