# v1.1 月次費用の編集・削除、重複確認、投資家向け資金収支ウォーターフォール

記録日：2026-10-15 JST
対象：`develop/v1.1-foundation`。公開`main`および`index.html`は変更しない。
完成状態：**概算投資判断用の開発環境で、費目編集・削除・重複確認・投資収支明細の一連の導線を実装。** 正式ブラウザE2E、旧v1移行、法定の税務申告精度は未完。

## 1. 実装した操作

### 1.1 明細の変更と削除

`src/v11-quick-input.mjs`に`editV11QuickLine`、`removeV11QuickLine`を追加。UIの「主要費目のクイック入力」の登録済み明細一覧に、行ごとの金額入力・更新ボタン・削除ボタンを追加した。

- 対象は**ユーザーがクイック入力として作成した月次費用**と**クイック入力由来の改修・FF&E資産**だけ。従来の手入力`expenses[]`や土地・建物取得原価を編集・削除してはならない。
- 編集／削除APIは`structuredClone`で**元データを変更せずに新しい文書を返す**。UIは明示的なボタン操作を通じて現在の下書きに反映。削除ではユーザー確認ダイアログを表示し、保存済みデータへは「保存」操作を行うまで反映しない。
- 改修費の編集・削除では`grossCost`、`taxBasis`、`taxBookValue`と非土地・建物資産の合計`K01`を更新。CapExは**営業費用へ二重算入しない**。初期月の支出はCF₀、途中月の支出は当年度ICFへ1回計上する。
- 現時点で改修費の**税務上の償却・消費税仕入控除・残存売却簿価**の自動計算は行わず、**概算税引後評価にも投資キャッシュアウトとしてのみ反映**する。この点はUIとドキュメントに明記する。

### 1.2 重複警告

`inspectV11QuickInputConflicts`は、全ての費用IDの重複を不正データとして拒否し、次を**確認警告**として返す。

- 同じ月・同じ費用分類・同額の明細がクイック入力と手入力／他のクイック入力で存在する（請求書が別なら正当な場合あり）。
- 物件の月次保有費`A05`とクイック`propertyOperating`費が、同じ費目を含む可能性。
- 宿泊固定費`H10`／`H12`、賃貸運営費`R05`／`R08`とクイック明細の金額が一致する可能性。
- 宿泊OTA料率`H08`と「OTA」「Booking」「予約サイト」「commission」等の説明を持つ手入力の宿泊営業費用の二重計上可能性。
- `K01`の設備投資総額と非土地建物資産合計の不一致。

警告は**本人に確認させるためのもので、自動削除・自動差引ではない**。同じ分類・月・同額の支払が真に別の請求であってもあり得るため、単純なキーワード・金額検知から断定してはならない。また、検出対象以外の重複は存在し得る。現状の簡易入力では請求書明細を統一正本として照合する機能はない。

## 2. 投資家ウォーターフォール

`src/v11-investor-waterfall.mjs`の`buildV11InvestorWaterfall({document,preview})`は、`previewV11Scenario`の**計算済み月次営業データ＋設備・取得・売却・融資イベント＋概算VAT・納税予定イベント**を独立再集計する。元データの単なるNPV値を再表示しているのではなく、元イベントごとの収支差額を検算する。

| 収支区分 | 表示・取扱い |
|---|---|
| 初期CF₀ | 取得価格・購入諸費用・初月の改修CapEx・敷金預入・初期融資実行・融資手数料を、初期自己資金CF₀として**1回のみ**記録 |
| 営業受取 | 宿泊／住宅賃貸の現金売上を区分 |
| 営業支出 | 月次営業費用・借上賃料・固定費・運転資金増減をまとめて表示。ただし元データでは個別の営業費用として保存 |
| 投資支出 | 中途改修・資産購入・維持CapExをICFへ区分。非現金償却費はここで二重に現金控除しない |
| 融資 | 融資実行、定期元本返済、繰上・売却時一括完済、支払利息・融資手数料を**営業利益と分離** |
| 売却・退出 | 売却代金、仲介手数料・売却諸費用・退出義務、敷金返還 |
| 税金 | **概算モード時に限り**所得税・譲渡税・法人税・消費税の現金差分を納付予定年に反映 |
| 年次・累計 | 税引前のCFと概算税引後の自己資本CF、初期CF₀を起点とする年末累積額、概算年末資金不足額 |
| 検算 | ① CF₀、②毎年のOCF/ICF/FinCF、③税・VATイベントを統合した概算税引後CF、④全期間合計が元の`previewV11Scenario`の投資CFと一致しなければ例外として表示停止 |

### 特に重要な検算

```text
現金税引前Equity CF
  = 宿泊・賃貸営業収入 + 営業現金費用（マイナス）− 運転資金増加
    + 取得・設備投資・売却・敷金その他のICF
    + 借入実行 − 元本返済 − 利息・融資手数料

概算税引後Equity CF
  = 現金税引前Equity CF + VAT関連受払・精算CF
    + 所得税・譲渡税等の現金納付CF（マイナス）

全期間の現金回収差額
  = CF₀ + Σ [投資保有年CF] + Σ [退出後の残余納税CF]
```

- 初月に取得・売却するケースでも、取得時支出はCF₀、売却時受取・ローン出口返済は年1のCFとして二重計上しない。
- **税引前投資CFの評価対象は保有年数まで**、納税CFは売却後の年度に残ることがある。税引前CFの評価期間外の年には現金収入を推定せず**ゼロ**を補完する一方、2027/2028年の税金は明示。
- **累積年末の最大資金不足額**は年次・CF₀ベースの簡便指標であり、月中の資金不足・資金調達必要額の上限を意味しない。運転資本・月中融資返済の最低現金残高は将来の月次計算工程で扱う。
- 融資元本は金融CF、減価償却は非現金税務費用。混合しない。
- 売却後の住民税や、課税仕入VATについて法的適格性が不明な場合は**概算シナリオ仮定**であり、申告精度は保証しない。

## 3. 表示機能

開発用`preview/v11-dev.html`（分析タブ）に以下を追加：
1. 費目の個別編集・削除ボタン、既存の手入力費用・数値項目との重複警告。
2. 取得・改修・営業・金融・売却・税金を年次で確認するウォーターフォール表。
3. CF₀・物件取得・融資実行・利息・元本返済・売却総額・税負担・年末累積の簡便なKPI。
4. 折り畳み可能な設備投資・借入返済・売却諸費用の明細表。

費用更新後は保存用の下書きの変更扱いとなり、再計算される。保存正本・公開v1は自動変更されない。
