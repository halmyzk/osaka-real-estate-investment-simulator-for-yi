# v1.1 購入M4物件の資産台帳・減価償却・譲渡税の縦断実装

記録日：2026-10-14（JST）
対象：`develop/v1.1-foundation`（`main`・公開 `index.html` の更新なし）
状態：**限定シナリオを実装・独立検算済み。税務適格性・本番UI・正式な税引後Equity CFは未承認。**

## 1. なぜこの段階を実装したか

従来の `src/v11-derived-ordinary-tax.mjs` は、賃借物件の通常所得から試算した税額を翌年の納付CFへ接続するが、購入物件の土地・建物原価や売却時の調整後取得費を保証できず、購入物件の税引後評価を停止していた。

今回、**本当に保存されたv1.1形式の資産台帳**と、計算済みの営業CF／投資CF／金融CFを照合する `src/v11-owned-property-tax.mjs` を追加。限られた条件下のM4購入物件について：
- 初期A01購入CF＝土地＋建物の税務取得価額、土地・建物の登録は**新しいCapExを生じない**。
- 建物は年度別、評価根拠を添えた定額償却。土地は非償却。償却費は税務所得だけ減らし、投資CFを再減算しない。
- 売却CFのグロス受取と売却費用を取得費調整後の土地／建物税務簿価と突き合わせ、譲渡益を計算。
- **個人**：譲渡年1月1日時点の長短判定を行い、分離譲渡税として通常の賃貸所得税から独立。
- **法人**：法人売却益を法人課税所得へ算入し、個人の長短分離税率を流用しない。
- 売却後の所得税・住民税を暦年CFへ加算し、年末売却後の翌年／翌々年の残余納税を消さない。

## 2. 適用できる限定条件（満たさなければ `incomplete`）

1. **M4通年賃貸の購入物件**。取得・営業開始は1月1日、処分は12月31日、途中の自己居住・非業務用期間なし。
2. **課税主体＝所有主体＝運営主体**。所有・運営が別法人／別人なら別の内部取引モデルが必要。
3. **取得税務台帳は土地1件＋建物1件**。取得時価額・税務取得原価・初期税務簿価が一致し、その合計がGate Aの購入CFと完全に一致。
4. **土地は非償却**。建物は確認済みの直線定額償却の年率、法定耐用年数、事業開始日、年度ごと100%事業使用の証拠を要求。根拠URL／ルール版／法的適格性審査を明示。
5. 追加の建物附属設備、造作・改装、家具、修繕・資本的支出、取得諸費用の資本化・売却義務の処理は**未接続**。一件でも該当する支出があれば税務計算を保留。
6. 個人の居住用財産の特別控除・軽減税率を自動適用しない。譲渡損の控除・通算可否も未対応のため、単純に税額0円にせず保留。
7. 個人の譲渡税率・付加税・普通徴収の納付月は**税制年度・自治体・納税者による審査済みのシナリオ仮定**。原典URLの存在のみで個別適用を認定しない。
8. 消費税、源泉徴収、取得時の登録免許税・不動産取得税、法定の端数処理、税務簿価の個人家事按分、修繕資本判定はなお別工程。**正式`afterTax`は`null`を維持**。

## 3. 独立検算ゴールデンケース（すべて架空）

`preview/v11-owned-property-sample.json` と、同じ文書にハッシュで結び付けた `preview/v11-owned-property-tax-plan.json` を使用。個人がM4物件を購入し、法人が別のM4を賃借する2主体／2住戸モデル。

| 明細 | 値 | 計算 |

| 購入価格 | 1,000,000円 | A01、CF0で一度支払 |
| 土地の取得原価 | 400,000円 | 非償却 |
| 建物の取得原価 | 600,000円 | 定額償却の対象 |
| 建物の年度償却率（仮定） | 5% | 耐用年数20年・率の適格性は個別審査 |

| 売却総額 | 1,200,000円 | 売却CFはICFに一度だけ計上 |
| 売却費用 | 10,000円 | 税務上の譲渡費用適格性を別審査 |
| 個人の譲渡益 | **220,000円** | 1,200,000−10,000−970,000 |

| 譲渡税の現金支払予定 | 2027年3月／2027年6・8・10月／2028年1月 | **予定納付月の仮定**。実際の納税通知書や休日調整は未照合 |
| 個人＋法人の初期自己資金CF0 | **−1,100,000円** | 購入100万円＋賃借敷金10万円 |

建物償却率を5%から4%へ変えても**税引前CF0・税引前年度CFは不変**。建物税務簿価・通常所得税の控除額・譲渡益・分離譲渡税の納付CFのみ変化することをテスト。

### 法人所有物件の別パターン

同じ土地・建物を法人が所有する場合、譲渡益220,000円は**法人課税所得に一度だけ算入**し、個人の分離譲渡税を追加発生させない。二重計上防止・納税主体分離を `tests/v11-owned-property-tax.test.mjs` に固定。

## 5. コードと受入検証

- `src/v11-preview-engine.mjs`：土地・建物台帳を認識してもA01購入CF以外のCapExを追加しない。
- `src/v11-owned-property-tax.mjs`：所有M4の取得CF・事業用用途・年率・年次償却・売却簿価・個人／法人の譲渡益と納税月を一元監査。
